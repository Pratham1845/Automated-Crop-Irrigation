Interdisciplinary project

About the project

Connecting IoT concepts, weather intelligence and business thinking.

✦

Automated Crop Irrigation Using Weather Forecasting

This project demonstrates how soil-moisture readings and weather forecasts can support timely, resource-conscious irrigation decisions. It is intentionally designed as a browser-based simulation for academic demonstration.

Problem statement

Over-irrigation wastes water and energy, while under-irrigation can reduce crop health. Farmers need accessible decision support that considers both field moisture and upcoming rainfall.

Aim & objectives

  • Reduce avoidable irrigation through forecast-aware decisions.
  • Present sensor and weather context in an understandable dashboard.
  • Explore the business case for a small smart-farming solution.

Two disciplines, one solution

⌘
BCA contribution

Frontend engineering, JavaScript decision logic, API integration, charts, local storage and responsive UX.

◫
MBA contribution

Cost modeling, value proposition, savings assumptions, stakeholder thinking and responsible adoption.

Concept flow

Soil data→Forecast→Decision→Action

Expected outcomes

A clear prototype for explaining how data can make irrigation more efficient, while keeping human review and agricultural expertise in the loop.

Future scope & limitations

Future work could connect calibrated sensors, secure user accounts, local weather services and field-level analytics. This prototype has no hardware connection, database, authentication or guaranteed forecast accuracy.
